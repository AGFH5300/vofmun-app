# Historical MUN Hub app source — november-2025

This is an archival import of one VOFMUN App/MUN Hub source folder from late 2025, not a recovered original Git commit chronology. The original source directory has no Git history. The two separate 2025 snapshots are imported as sequential source commits/tags on a dedicated history branch in the EXISTING public AGFH5300/vofmun-app repository. The existing GitHub main branch and running application were NOT changed.

One original file, scripts/seed-database.js, included five demonstration email IDs and nine hardcoded passwords. This archival copy replaces those emails with @example.invalid and passwords with null, and adds an unconditional error preventing accidental use of this historic seed script. All other 189 original files match their Mac source bytes exactly. Original Mac archive and private emergency recovery vault are unchanged.

Source includes React/Vite MUN Hub components, message/committee/chair/admin flows. Historical source functionality was not run or verified. The current GitHub main remains the latest app version, and is used for portable staging, not these old snapshots.
